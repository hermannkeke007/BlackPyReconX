Configuration des Clés API

Les clés API essentielles ne sont pas configurées. Veuillez suivre les étapes ci-dessous :

1. Créez un fichier `.env` : Copiez le fichier `.env.example` vers un nouveau fichier nommé `.env` à la racine du projet.

2. Remplissez vos clés API : Ouvrez le fichier `.env` et remplacez les valeurs `VOTRE_CLE_API...` par vos **vraies clés API**.
Ex: `SHODAN_API_KEY="votre_clé_shodan_ici"`

3. Redémarrez le framework : Une fois le fichier `.env` configuré, relancez `python start_all.py` dans votre terminal.
